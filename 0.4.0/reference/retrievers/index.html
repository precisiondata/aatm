    Retrievers

    Define retriever abstractions and vector-database-backed retrieval implementations.

    This module provides the base interface for retrieval components used in the pipeline, along with retrievers backed by a vector database: ChromaDBRetriever (a local or Chroma Cloud collection) and PineconeRetriever (a Pinecone index). Both share their filtering logic through VectorStoreRetriever. Retrievers are responsible for accepting one or more queries, fetching candidate expressions, and returning them in a standardized RetrieverResults structure.

    The module is designed to support pipeline-style composition, allowing retrievers to be chained with other components such as rerankers and selectors.

    FilterStrategy = Literal['overfetch_fallback', 'overfetch', 'native', 'chroma'] module-attribute

    How a VectorStoreRetriever applies a where metadata filter.

    • "overfetch_fallback" (default for ChromaDB): query without the filter for more results than needed, keep the ones that match the filter, and run the database's filtered query for the queries where fewer than top_k matches survive.
    • "overfetch": the same over-fetch, without the fallback. A query may then return fewer than top_k results.
    • "native" (default for Pinecone): pass the filter to the vector database. ChromaDB applies it before the vector search, which is exact but slow on large collections when many records match; Pinecone applies it during the search, so the over-fetch is not needed there.
    • "chroma": the same as "native", under its original name.

    EmbeddingFunction = Callable[..., Any] module-attribute

    Turns a list of texts into one vector each: embedding_function(input=texts).

    Any of aatm.embedding_functions works, as does any chromadb.EmbeddingFunction. An embed_query method, when present, is used for queries.

    class BaseRetriever(PipelineBaseClass, ABC):
    """Define the abstract interface for retrieval pipeline components.

    This base class establishes the contract for retrievers that accept one or
    more queries and return structured retrieval results. It also provides a
    flexible ``__call__()`` implementation that normalizes several supported
    query input types before delegating to ``retrieve()``.
    """

    @abstractmethod
    def retrieve(self, queries: List[str]) -> RetrieverResults:
        """Retrieve candidate results for one or more query strings.

        Subclasses must implement this method to perform the actual retrieval
        operation and return results in a ``RetrieverResults`` object.

        Args:
            queries: A list of query strings to retrieve candidates for.

        Returns:
            A ``RetrieverResults`` instance containing the retrieved candidates
                for each query.

        Raises:
            NotImplementedError: If the subclass does not override this method.
        """
        pass

    def __call__(  # type: ignore[override]
        self,
        queries: str | Translation | List[str] | List[Translation],
        *args: Any,
        **kwargs: Any,
    ) -> RetrieverResults:
        """Normalize query inputs and perform retrieval.

        This method allows retriever instances to be called directly with a
        single string, a single ``Translation`` object, a list of strings, or a
        list of ``Translation`` objects. Supported inputs are converted into a
        list of query strings before being passed to ``retrieve()``.

        Args:
            queries: Query input to retrieve against. Supported values are a
                single string, a single ``Translation`` object, a list of
                strings, or a list of ``Translation`` objects.

        Returns:
            A ``RetrieverResults`` instance containing the retrieved candidates
                for each normalized query string.

        Raises:
            AssertionError: If the input is not one of the supported query
                formats or does not contain valid string queries.
        """
        if isinstance(queries, str):
            queries = [queries]
        elif isinstance(queries, Translation):
            queries = [queries.text]
        elif (
            isinstance(queries, list)
            and queries
            and isinstance(queries[0], Translation)
        ):
            queries = [t.text for t in queries]

        assert isinstance(queries, list) and queries and isinstance(queries[0], str), (
            "queries must be a string, a Translation, a list of strings, or a list "
            f"of Translation objects. Got {queries}."
        )

        return self.retrieve(queries, *args, **kwargs)

    VectorStoreRetriever

    Bases: BaseRetriever

    Retrieve candidate expressions from a vector database.

    Queries are embedded with embedding_function and sent to a aatm.vector_stores.VectorStore. Retrieved metadata and distances are converted into RetrievedExpressionMetadata objects and returned in a standardized RetrieverResults container. Distances mean the same on every backend (see aatm.vector_stores), so selectors and thresholds do not depend on it.

    The retriever supports default filtering through a where clause and a configurable default number of results per query.

    filter_strategy chooses how a where filter is applied (see FilterStrategy). With "overfetch_fallback", the retriever first queries without the filter for max(top_k * overfetch_factor, min_overfetch) results, then, for the queries still short of top_k matches, for max_overfetch results, and only then falls back to the database's filtered query. With an exact search, the top_k matches that survive would be exactly the filtered query's results. Vector indexes are approximate, so in practice both methods miss some neighbours, in different places: the over-fetch misses matches that sit deep in the unfiltered ranking (a filter that fits the query poorly), while ChromaDB's filtered search can miss even close matches. Raise min_overfetch / max_overfetch for deeper filters. Query sizes are capped at the store's max_top_k.

    class VectorStoreRetriever(BaseRetriever):
    """Retrieve candidate expressions from a vector database.

    Queries are embedded with ``embedding_function`` and sent to a
    `aatm.vector_stores.VectorStore`. Retrieved metadata and distances are
    converted into ``RetrievedExpressionMetadata`` objects and returned in a
    standardized ``RetrieverResults`` container. Distances mean the same on
    every backend (see `aatm.vector_stores`), so selectors and thresholds do
    not depend on it.

    The retriever supports default filtering through a ``where`` clause and a
    configurable default number of results per query.

    ``filter_strategy`` chooses how a ``where`` filter is applied (see
    `FilterStrategy`). With ``"overfetch_fallback"``, the retriever first
    queries without the filter for ``max(top_k * overfetch_factor,
    min_overfetch)`` results, then, for the queries still short of ``top_k``
    matches, for ``max_overfetch`` results, and only then falls back to the
    database's filtered query. With an exact search, the ``top_k`` matches that
    survive would be exactly the filtered query's results. Vector indexes are
    approximate, so in practice both methods miss some neighbours, in different
    places: the over-fetch misses matches that sit deep in the unfiltered
    ranking (a filter that fits the query poorly), while ChromaDB's filtered
    search can miss even close matches. Raise ``min_overfetch`` /
    ``max_overfetch`` for deeper filters. Query sizes are capped at the
    store's ``max_top_k``.
    """

    def __init__(
        self,
        store: VectorStore,
        embedding_function: EmbeddingFunction,
        top_k: int = 10,
        where: dict[str, Any] | None = None,
        filter_strategy: FilterStrategy | None = None,
        overfetch_factor: int = 20,
        min_overfetch: int = 1000,
        max_overfetch: int = 5000,
        *args: Any,
        **kwargs: Any,
    ):
        """Initialize the retriever.

        Args:
            store: The vector database index to query.
            embedding_function: Embeds the queries, with the model the index
                was built with.
            top_k: Default number of candidate results to return per query.
            where: Optional metadata filter applied to all queries unless
                overridden at retrieval time.
            filter_strategy: How a ``where`` filter is applied. See
                `FilterStrategy`. Defaults to ``"native"`` for a store that
                filters during the search (Pinecone), and to
                ``"overfetch_fallback"`` otherwise (ChromaDB).
            overfetch_factor: The first unfiltered query fetches
                ``top_k * overfetch_factor`` results (at least
                ``min_overfetch``).
            min_overfetch: Lower bound on the first unfiltered query's size.
            max_overfetch: Size of the second, wider unfiltered query, run for
                the queries the first one left short of ``top_k`` matches.
                Skipped when it is not larger than the first query.
            *args: Additional positional arguments reserved for compatibility.
            **kwargs: Additional keyword arguments reserved for compatibility.
        """
        self.store = store
        self.embedding_function = embedding_function
        if filter_strategy is None:
            filter_strategy = (
                "native" if store.filters_during_search else "overfetch_fallback"
            )
        self._configure(
            top_k,
            where,
            filter_strategy,
            overfetch_factor,
            min_overfetch,
            max_overfetch,
        )

    def _configure(
        self,
        top_k: int,
        where: dict[str, Any] | None,
        filter_strategy: FilterStrategy,
        overfetch_factor: int,
        min_overfetch: int,
        max_overfetch: int,
    ) -> None:
        self.top_k = top_k
        self.where = where
        self.filter_strategy = _check_strategy(filter_strategy)
        if overfetch_factor < 1 or min_overfetch < 1 or max_overfetch < 1:
            raise ValueError(
                "overfetch_factor, min_overfetch and max_overfetch must be >= 1."
            )
        self.overfetch_factor = overfetch_factor
        self.min_overfetch = min_overfetch
        self.max_overfetch = max_overfetch

    @property
    def max_query_size(self) -> int | None:
        """Largest number of results one query may ask for, or ``None``."""
        return self.store.max_top_k

    def content_fingerprint(self) -> dict[str, Any] | None:
        """Identify the index content, for the coding cache (`aatm.omop.cache`)."""
        return self.store.fingerprint()

    def retrieve(
        self,
        queries: List[str],
        where: dict[str, Any] | None = None,
        top_k: int | None = None,
        filter_strategy: FilterStrategy | None = None,
        *args,
        **kwargs,
    ) -> RetrieverResults:
        """Retrieve nearest candidates for the given queries.

        This method submits the provided query strings to the vector database,
        optionally overriding the default metadata filter and number of
        returned results. It then converts the raw response into
        ``RetrievedExpressionMetadata`` objects grouped by query and wraps them
        in a ``RetrieverResults`` instance.

        Args:
            queries: List of query strings to search for.
            where: Optional metadata filter to apply to this retrieval call. If
                not provided, the retriever's default filter is used.
            top_k: Optional number of results to return per query. If not
                provided, the retriever's default ``top_k`` value is used.
            filter_strategy: Optional override of the retriever's
                ``filter_strategy`` for this call. Ignored without a filter.

        Returns:
            A ``RetrieverResults`` instance containing processed retrieval
                results for each query, including distances and metadata.

        Raises:
            UnsupportedFilterError: With ``filter_strategy="overfetch"``, if the
                filter has a shape `is_supported_filter` rejects. The default
                strategy hands such filters to the database instead.
            Exception: Propagates errors raised by the underlying vector
                database client.
        """
        n_results = top_k if top_k is not None else self.top_k
        where = where if where is not None else self.where
        strategy = _check_strategy(
            filter_strategy if filter_strategy is not None else self.filter_strategy
        )

        hits: list[list[_Hit]]
        if not where:
            hits = self._query(query_texts=queries, n_results=n_results)
        elif strategy in ("native", "chroma") or (
            strategy == "overfetch_fallback" and not is_supported_filter(where)
        ):
            hits = self._query(query_texts=queries, n_results=n_results, where=where)
        else:
            if not is_supported_filter(where):
                raise UnsupportedFilterError(
                    f"Cannot evaluate filter in Python: {where!r}. Use "
                    "filter_strategy='native' or 'overfetch_fallback' for it."
                )
            hits = self._overfetch(
                queries,
                where,
                n_results,
                fallback=strategy == "overfetch_fallback",
            )

        processed_results = [
            [self._to_result(distance, metadata) for distance, metadata in query_hits]
            for query_hits in hits
        ]

        return RetrieverResults(
            results=processed_results,
            queries=queries,
        )

    def _to_result(
        self, distance: float, metadata: dict[str, Any]
    ) -> RetrievedExpressionMetadata:
        """Turn one retrieved record into a result."""
        return RetrievedExpressionMetadata(distance=distance, **metadata)  # type: ignore[arg-type]

    def overfetch_sizes(self, top_k: int) -> list[int]:
        """The sizes of the unfiltered queries the over-fetch runs, in order."""
        first = max(top_k * self.overfetch_factor, self.min_overfetch)
        second = self.max_overfetch
        cap = self.max_query_size
        if cap is not None:
            first, second = min(first, cap), min(second, cap)
        return [first, second] if second > first else [first]

    def _overfetch(
        self,
        queries: List[str],
        where: dict[str, Any],
        top_k: int,
        fallback: bool,
    ) -> list[list[_Hit]]:
        """Query without the filter, filter in Python, widen, then fall back."""
        # Embed once: the wider query and the fallback reuse the embeddings.
        embeddings = list(self._embed_queries(queries))
        hits: list[list[_Hit]] = [[] for _ in queries]
        pending = list(range(len(queries)))

        for size in self.overfetch_sizes(top_k):
            batch = self._query(
                query_embeddings=[embeddings[i] for i in pending], n_results=size
            )
            still_short = []
            for i, query_hits in zip(pending, batch):
                matching = [hit for hit in query_hits if _matches(hit[1], where)]
                hits[i] = matching[:top_k]
                # Fewer results than asked for: the whole collection was seen,
                # so no wider query or fallback can find more matches.
                if len(matching) < top_k and len(query_hits) >= size:
                    still_short.append(i)
            pending = still_short
            if not pending:
                return hits

        if fallback:
            batch = self._query(
                query_embeddings=[embeddings[i] for i in pending],
                n_results=top_k,
                where=where,
            )
            for i, query_hits in zip(pending, batch):
                hits[i] = query_hits
        return hits

    def _embed_queries(self, queries: List[str]) -> Any:
        """Embed query texts, with ``embed_query`` when the function has one."""
        embed_query = getattr(self.embedding_function, "embed_query", None)
        if callable(embed_query):
            return embed_query(input=queries)
        return self.embedding_function(input=queries)

    def _query(
        self,
        n_results: int,
        query_texts: List[str] | None = None,
        query_embeddings: Sequence[Any] | None = None,
        where: dict[str, Any] | None = None,
    ) -> list[list[_Hit]]:
        """Run one query per text or embedding and return its (distance, metadata)."""
        if query_embeddings is None:
            assert query_texts is not None, "query_texts or query_embeddings needed"
            query_embeddings = list(self._embed_queries(query_texts))
        if self.max_query_size is not None:
            n_results = min(n_results, self.max_query_size)
        return self.store.query(query_embeddings, top_k=n_results, where=where)

    self,
    queries: List[str],
    where: dict[str, Any] | None = None,
    top_k: int | None = None,
    filter_strategy: FilterStrategy | None = None,
    *args,
    **kwargs,

    This method submits the provided query strings to the vector database,
    optionally overriding the default metadata filter and number of
    returned results. It then converts the raw response into
    ``RetrievedExpressionMetadata`` objects grouped by query and wraps them
    in a ``RetrieverResults`` instance.

    Args:
        queries: List of query strings to search for.
        where: Optional metadata filter to apply to this retrieval call. If
            not provided, the retriever's default filter is used.
        top_k: Optional number of results to return per query. If not
            provided, the retriever's default ``top_k`` value is used.
        filter_strategy: Optional override of the retriever's
            ``filter_strategy`` for this call. Ignored without a filter.

    Returns:
        A ``RetrieverResults`` instance containing processed retrieval
            results for each query, including distances and metadata.

    Raises:
        UnsupportedFilterError: With ``filter_strategy="overfetch"``, if the
            filter has a shape `is_supported_filter` rejects. The default
            strategy hands such filters to the database instead.
        Exception: Propagates errors raised by the underlying vector
            database client.
    """
    n_results = top_k if top_k is not None else self.top_k
    where = where if where is not None else self.where
    strategy = _check_strategy(
        filter_strategy if filter_strategy is not None else self.filter_strategy
    )

    hits: list[list[_Hit]]
    if not where:
        hits = self._query(query_texts=queries, n_results=n_results)
    elif strategy in ("native", "chroma") or (
        strategy == "overfetch_fallback" and not is_supported_filter(where)
    ):
        hits = self._query(query_texts=queries, n_results=n_results, where=where)
    else:

            raise UnsupportedFilterError(
                f"Cannot evaluate filter in Python: {where!r}. Use "
                "filter_strategy='native' or 'overfetch_fallback' for it."
            )
        hits = self._overfetch(
            queries,
            where,
            n_results,
            fallback=strategy == "overfetch_fallback",
        )

        [self._to_result(distance, metadata) for distance, metadata in query_hits]
        for query_hits in hits
    ]

    return RetrieverResults(
        results=processed_results,
        queries=queries,
    )

    def is_supported_filter(where: Any) -> bool:
    """Whether `matches_filter` can evaluate a ChromaDB `where` filter.

    Supported: field equality (``{"field": value}`` or
    ``{"field": {"$eq": value}}``), ``{"field": {"$in": [...]}}``, and
    ``$and`` / ``$or`` over supported filters. Like ChromaDB, each dict holds
    exactly one key.
    """
    if not isinstance(where, Mapping) or len(where) != 1:
        return False
    ((key, value),) = where.items()
    if key in ("$and", "$or"):
        return (
            isinstance(value, Sequence)
            and not isinstance(value, str)
            and len(value) > 0
            and all(is_supported_filter(clause) for clause in value)
        )
    if key.startswith("$"):
        return False
    if _is_scalar(value):
        return True
    if isinstance(value, Mapping) and len(value) == 1:
        ((op, operand),) = value.items()
        if op == "$eq":
            return _is_scalar(operand)
        if op == "$in":
            return (
                isinstance(operand, Sequence)
                and not isinstance(operand, str)
                and all(_is_scalar(item) for item in operand)
            )
    return False

    def record_vector_database(
    embedding_model: str,
    vector_db: VectorDbMode,
    location: str | Path,
    *,
    keep_date: bool = False,
) -> None:
    """Record in ``.aatm/config.yaml`` that a vector database is built.

    A record of the same model and vector database is replaced.

    Args:
        embedding_model: Registry name of the embedding model.
        vector_db: ``local``, ``cloud`` or ``pinecone``.
        location: The local directory, or the collection or index name.
        keep_date: Keep the build date of an existing record (an existing
            database kept as it was), and only date a new one.
    """
    config = _read_config()
    entries = [e for e in config.get("vector_databases") or [] if isinstance(e, dict)]
    previous = next(
        (
            e
            for e in entries
            if e.get("embedding_model") == embedding_model
            and e.get("vector_db") == vector_db
        ),
        None,
    )
    built_at = datetime.now(timezone.utc).isoformat(timespec="seconds")
    if keep_date and previous is not None and previous.get("built_at"):
        built_at = str(previous["built_at"])
    entries = [e for e in entries if e is not previous]
    entries.append(
        {
            "embedding_model": embedding_model,
            "vector_db": vector_db,
            "location": Path(location).as_posix()
            if vector_db == "local"
            else str(location),
            "built_at": built_at,
        }
    )
    config["vector_databases"] = entries
    CONFIG_PATH.parent.mkdir(parents=True, exist_ok=True)
    CONFIG_PATH.write_text(yaml.safe_dump(config, sort_keys=False), encoding="utf-8")

    def recorded_vector_databases(vector_db: str | None = None) -> list[BuiltStore]:
    """The vector databases recorded in ``.aatm/config.yaml``, newest first.

    Args:
        vector_db: Only those in this vector database (``local``, ``cloud`` or
            ``pinecone``). ``None`` returns all of them.
    """
    stores = []
    for entry in _read_config().get("vector_databases") or []:
        if not isinstance(entry, dict):
            continue
        model, mode = entry.get("embedding_model"), entry.get("vector_db")
        if not model or mode not in VECTOR_DB_MODES:
            continue
        if vector_db is not None and mode != vector_db:
            continue
        stores.append(
            BuiltStore(
                embedding_model=str(model),
                vector_db=cast(VectorDbMode, mode),
                location=str(entry.get("location", "")),
                built_at=str(entry["built_at"]) if entry.get("built_at") else None,
            )
        )
    # Newest first; of two built in the same second, the one recorded last.
    order = {id(store): i for i, store in enumerate(stores)}
    return sorted(stores, key=lambda s: (s.built_at or "", order[id(s)]), reverse=True)

    def built_vector_databases(vector_db: str | None = None) -> list[BuiltStore]:
    """Find the embedding models whose vector database is built and not empty.

    Args:
        vector_db: ``local``, ``cloud`` or ``pinecone``. If ``None``,
            ``AATM_VECTOR_DB`` decides, and otherwise ``local``.

    Raises:
        VectorDatabaseConfigError: If the vector database configuration is
            invalid, e.g. cloud mode without ``CHROMA_API_KEY``.
    """
    from aatm.registries.retrievers import CHROMADB_RETRIEVER_MODEL_REGISTRY

    mode = resolve_vector_db_mode(vector_db)
    recorded = {s.embedding_model: s for s in recorded_vector_databases(mode)}
    stores = []
    for name, spec in CHROMADB_RETRIEVER_MODEL_REGISTRY.items():
        location, count, reason = _store_status(spec, mode)
        if reason is None:
            built_at = recorded[name].built_at if name in recorded else None
            stores.append(BuiltStore(name, mode, location, count, built_at))
    return stores

    def check_built(
    embedding_model: str, vector_db: str | None = None, local_path: str | None = None
) -> None:
    """Raise unless the vector database of ``embedding_model`` is built.

    Args:
        embedding_model: Registry name of the embedding model.
        vector_db: ``local``, ``cloud`` or ``pinecone``. If ``None``,
            ``AATM_VECTOR_DB`` decides, and otherwise ``local``.
        local_path: Directory of the local database, in local mode. Defaults
            to the model's directory under ``.aatm/chroma_vector_dbs``.

    Raises:
        VectorDatabaseNotBuiltError: If the database does not exist or is
            empty. The message lists the databases that are built and how to
            build this one.
    """
    from aatm.registries.retrievers import CHROMADB_RETRIEVER_MODEL_REGISTRY

    mode = resolve_vector_db_mode(vector_db)
    spec = CHROMADB_RETRIEVER_MODEL_REGISTRY[embedding_model]
    _, _, reason = _store_status(spec, mode, local_path)
    if reason is None:
        return
    built = built_vector_databases(mode)
    lines = [f"No vector database for '{embedding_model}' ({reason})."]
    if built:
        lines += ["Built and ready:", _list_built(built)]
        lines.append(
            f'Use retriever="{built[0].embedding_model}", or build it with: '
            + _build_command(embedding_model, mode)
        )
    else:
        lines.append(
            f"No vector database is built in {mode} mode. Build it with: "
            + _build_command(embedding_model, mode)
        )
    raise VectorDatabaseNotBuiltError("\n".join(lines))

    def default_vector_database(vector_db: str | None = None) -> BuiltStore:
    """The vector database a retriever uses when none is given.

    The most recently built one recorded for the vector database, or, with no
    record, the only built one.

    Args:
        vector_db: ``local``, ``cloud`` or ``pinecone``. If ``None``,
            ``AATM_VECTOR_DB`` decides, and otherwise ``local``.

    Raises:
        NoVectorDatabaseError: If no vector database is built.
        VectorDatabaseNotBuiltError: If several are built and none is recorded,
            so the choice is the user's.
    """
    from aatm.registries.retrievers import CHROMADB_RETRIEVER_MODEL_REGISTRY

    mode = resolve_vector_db_mode(vector_db)
    recorded = [
        s
        for s in recorded_vector_databases(mode)
        if s.embedding_model in CHROMADB_RETRIEVER_MODEL_REGISTRY
    ]
    if recorded:
        name = recorded[0].embedding_model
        if len(recorded) > 1:
            others = ", ".join(s.embedding_model for s in recorded[1:])
            logger.info(
                f"Using retriever '{name}', the most recently built "
                f"{mode} vector database (also built: {others})"
            )
        else:
            logger.info(f"Using retriever '{name}', built by aatm init")
        return recorded[0]

    built = built_vector_databases(mode)
    if len(built) == 1:
        name = built[0].embedding_model
        logger.info(f"Using retriever '{name}', the only built {mode} vector database")
        return built[0]
    if not built:
        raise NoVectorDatabaseError(
            f"No vector database is built in {mode} mode, so there is no retriever "
            "to default to. Build one with: aatm init"
            + ("" if mode == "local" else f" --vector-db {mode}")
        )
    raise VectorDatabaseNotBuiltError(
        "Several vector databases are built and none is recorded in "
        f"{CONFIG_PATH.as_posix()}:\n{_list_built(built)}\n"
        f'Choose one, e.g. retriever="{built[0].embedding_model}".'
    )
