    Decision models

    Decision models answer closed-set questions about a state (a text or a JSON record): pick one of several options, place it on an ordered scale, or answer yes or no. They return the answer with a probability per option, faster and cheaper than a generative LLM call, and write no text.

    Many steps of a mapping or extraction pipeline are decisions of this kind: choosing a candidate concept, labelling an attribute, checking that a mention is not negated. The first such step is DecisionSelector; see issue #77 for the others planned on top of this interface.

    import asyncio

from aatm.llm import Question, create_decision_model

model = create_decision_model("openrouter/typesafe/jev-1.13")
decision = asyncio.run(
    model.decide(
        {"text": "creatinine", "unit": "mg/dl", "value": "1.4"},
        [
            Question.choice(
                "specimen",
                "Which specimen was the test most likely done on?",
                {"serum": "Serum or plasma", "urine": "Urine", "unknown": "Not stated"},
            ),
            Question.score(
                "abnormal", "How abnormal is the value?", ["normal", "mild", "severe"]
            ),
            Question.predicate("is_lab", "Is the text the name of a lab test?"),
        ],
    )
)
decision["specimen"].value          # "serum"
decision["specimen"].probabilities  # {"serum": 0.82, "urine": 0.11, "unknown": 0.07}
decision["abnormal"].label          # the most likely level
decision["is_lab"].probability      # probability of yes

    Model id Backend Key Probabilities

    gemini/gemini-decision-1 Gemini Decisions API (v1beta) GOOGLE_API_KEY or GEMINI_API_KEY yes

    jev-compatible/<model> + base_url Any endpoint with Jev's request shape: TypeSafe, Eden AI, a self-hosted model api_key= yes
    llm/<llm id>, e.g. llm/anthropic/claude-haiku-5-5 Any aatm.llm.create_llm model, through structured output the LLM's no

    llm/ models let pipeline steps run with any provider, or offline with a local model, but their answers carry no probabilities: thresholds on probabilities do not apply to them.

    Calls share the rate limits and retries of aatm.llm.limits, and are counted by aatm.llm.track_usage. OpenRouter reports each call's cost, which TokenUsage.cost uses when you give no price for the model.

    Pin versions

    Aliases such as jev-latest move: the answers behind cached results change. Use a versioned model id (typesafe/jev-1.13); aatm warns about latest and preview aliases.

    Data governance

    Decision backends send the state, e.g. a sentence of a clinical note, to the provider: OpenAI, Google, OpenRouter and TypeSafe, or Eden AI. Before sending protected health information, check the provider's data processing agreement (and BAA, where required) and its data retention. Use llm/ with a local model to keep data on your machine.

    Probabilities are not accuracy

    A confident answer can be wrong, and some models' probabilities shift with the order of the options. Calibrate thresholds on your own labelled data.

    Selecting concepts: DecisionSelector

    DecisionSelector is a selector of the terminology mapper. For each text, it asks the decision model one choice question: which of the top-k retrieved candidate concepts means the same as the text, or none. Expressions of the same standard concept (synonyms) are one option, so their probability is not split.

    from aatm.omop import OmopTableBuilder
from aatm.terminology_mapper import TerminologyMapper

mapper = TerminologyMapper(
    retriever="text-embedding-3-small",
    selector="decision-openrouter/typesafe/jev-1.13",
)
builder = OmopTableBuilder(definitions, mapper=mapper)

    Registered names are decision-openai/gpt-6-luna, decision-gemini/gemini-decision-1 and decision-openrouter/typesafe/jev-1.13; any other decision-<model id> works too, e.g. decision-llm/ollama/llama3.1:8b. To set top_k, the question, or the model's api_key, base_url and settings, build the selector:

    from aatm.selectors import DecisionSelector

selector = DecisionSelector(
    "jev-compatible/jev-1.13",
    top_k=5,
    model_kwargs={"base_url": "https://jev.example.org/v1/decisions"},
)

    The probability of the chosen concept is the mapping's score: the mapper's confidence_score and the builder's score. A min_score in a definition is therefore a threshold on the model's probability: map: {min_score: 0.8} keeps the concepts chosen with at least 80 %, and stores 0 with a low_confidence issue for the others. Each mapping's trace has the provider's model version and the probability of every option.

    llm/ models give no score

    With an llm/ model the selector still chooses, but the mappings have no score (confidence_score is empty): a min_score rejects all of them. aatm warns when you create such a selector.

    The coding cache (aatm.omop.CachedCoder) keys results on the selector's cache_identity(): the model id, top_k, the question and the endpoint. Changing any of them, e.g. moving from jev-1.13 to jev-1.14, codes the texts again. A moving alias (jev-latest) would not: pin versions.

    The texts to map and the candidate names are sent to the provider; see the data governance warning above. The API reference of DecisionSelector is on the Selectors page.

    Decision models: closed-set questions answered with probabilities.

    A decision model does not write text. It reads a state (a text, or JSON) and answers declared questions, each with a closed set of answers, and returns the answer with a probability per option. Many pipeline steps are such decisions: picking a candidate concept, labelling an attribute, checking that a mention is not negated.

    from aatm.llm import Question, create_decision_model

model = create_decision_model("openrouter/typesafe/jev-1.13")
decision = await model.decide(
    {"text": "creatinine", "unit": "mg/dl"},
    [
        Question.choice(
            "specimen",
            "Which specimen was the test most likely done on?",
            {"serum": "Serum or plasma", "urine": "Urine", "unknown": "Not stated"},
        ),
        Question.predicate("is_lab", "Is the text the name of a lab test?"),
    ],
)
decision["specimen"].value, decision["specimen"].probabilities
decision["is_lab"].probability

    Question kinds:

    Kind Answers Answer.value
    choice one of 2–255 named options the option
    score an ordered scale of 2–10 levels, lowest first the probability-weighted position, from 0 (first level) to n - 1; Answer.label is the most likely level
    predicate yes or no True or False; Answer.probability is the probability of yes

    Backends (see create_decision_model):

    • openai/gpt-6-luna: the OpenAI Decisions API.
    • gemini/gemini-decision-1: the Gemini Decisions API.
    • openrouter/<model>: OpenRouter's decisions endpoint, e.g. TypeSafe's Jev (openrouter/typesafe/jev-1.13).
    • jev-compatible/<model>: any endpoint with the same request shape as Jev's (TypeSafe directly, Eden AI, a self-hosted model), with base_url.
    • llm/<llm id>: any StructuredLLM (e.g. llm/anthropic/claude-haiku-5-5), through structured output. Its answers have no probabilities, so pipeline steps work offline or with any provider, but thresholds on probabilities do not apply.

    Pin versions (jev-1.13, not jev-latest): a moving alias changes the answers behind cached results.

    Calls go through the shared rate limiter and retries (aatm.llm.limits) and are counted by aatm.llm.track_usage.

    Data governance: decision backends send the state, e.g. a sentence of a clinical note, to the provider. Check the provider's data processing terms and retention before sending protected health information.

    class Question(BaseModel):
    """A question with a closed set of answers.

    Build one with `Question.choice`, `Question.score` or `Question.predicate`.

    Attributes:
        name: Identifies the answer: a letter, then letters, digits or ``_``.
        kind: ``choice``, ``score`` or ``predicate``.
        instructions: The question, e.g. ``"Is the condition negated?"``.
        options: The options (choice) or the levels, lowest first (score). Empty for
            a predicate.
    """

    model_config = ConfigDict(extra="forbid", frozen=True)

    name: str
    kind: QuestionKind
    instructions: str = Field(min_length=1)
    options: tuple[Option, ...] = ()

    @model_validator(mode="after")
    def _check(self) -> "Question":
        if not _NAME.match(self.name):
            raise ValueError(
                f"Invalid question name {self.name!r}: use a letter, then up to 63 "
                "letters, digits or '_'."
            )
        values = [o.value for o in self.options]
        if len(set(values)) != len(values):
            raise ValueError(f"Question {self.name!r} has duplicate options.")
        n = len(self.options)
        if self.kind == "choice" and not 2 <= n <= MAX_CHOICES:
            raise ValueError(
                f"Choice question {self.name!r} needs 2 to {MAX_CHOICES} options, "
                f"got {n}."
            )
        if self.kind == "score" and not 2 <= n <= MAX_LEVELS:
            raise ValueError(
                f"Score question {self.name!r} needs 2 to {MAX_LEVELS} levels, got {n}."
            )
        if self.kind == "predicate" and n:
            raise ValueError(f"Predicate question {self.name!r} takes no options.")
        return self

    @classmethod
    def choice(
        cls,
        name: str,
        instructions: str,
        options: Union[Mapping[str, Optional[str]], Sequence[Union[str, Option]]],
    ) -> "Question":
        """A question answered by one of `options`.

        Args:
            options: ``{value: description}``, or values, or `Option` objects.
        """
        return cls(
            name=name,
            kind="choice",
            instructions=instructions,
            options=tuple(_options(options)),
        )

    @classmethod
    def score(
        cls,
        name: str,
        instructions: str,
        levels: Union[Mapping[str, Optional[str]], Sequence[Union[str, Option]]],
    ) -> "Question":
        """A question answered on an ordered scale.

        Args:
            levels: The levels, **lowest first**, as for `choice`.
        """
        return cls(
            name=name,
            kind="score",
            instructions=instructions,
            options=tuple(_options(levels)),
        )

    @classmethod
    def predicate(cls, name: str, instructions: str) -> "Question":
        """A yes/no question."""
        return cls(name=name, kind="predicate", instructions=instructions)

    @property
    def values(self) -> list[str]:
        """The option values, or level labels, in order."""
        return [o.value for o in self.options]

    @property
    def probability(self) -> Optional[float]:
        """Predicate: the probability of yes. Choice and score: of the answer."""
        if self.kind == "predicate":
            return self.probabilities.get("true")
        key = self.label if self.kind == "score" else self.value
        return self.probabilities.get(str(key)) if key is not None else None

    class LLMDecisionModel:
    """Any `StructuredLLM` used as a decision model, through structured output.

    The answers have the chosen value but **no probabilities and no confidence**: an
    LLM's verbal answer is not a probability. Use it to run pipeline steps without a
    decision provider, not to calibrate thresholds.
    """

    def __init__(self, llm: StructuredLLM):
        self.llm = llm
        self.model_id = f"llm/{llm.model_id}"

    async def decide(self, state: State, questions: Sequence[Question]) -> Decision:
        check_questions(questions)
        output_type = _output_type(questions)
        user = (
            "# State\n"
            + state_text(state)
            + "\n\n# Questions\n\n"
            + "\n\n".join(_question_text(q) for q in questions)
        )
        output = await self.llm.generate(
            system=_LLM_SYSTEM, user=user, output_type=output_type
        )
        answers: list[Answer] = []
        for i, question in enumerate(questions):
            value = getattr(output, f"q{i}")
            if question.kind == "score":
                position = question.values.index(value)
                answers.append(
                    Answer(
                        name=question.name,
                        kind="score",
                        value=float(position),
                        label=value,
                    )
                )
            else:
                answers.append(
                    Answer(name=question.name, kind=question.kind, value=value)
                )
        return Decision(model=self.llm.model_id, answers=answers)

        self, body: dict[str, Any], questions: Sequence[Question]

    def jev_answer(model_id: str, question: Question, raw: Any) -> Answer:
    """Parse an answer in Jev's shape (also the Gemini Decisions API's).

    Raises:
        DecisionError: If the answer is missing, of the wrong type or malformed.
    """
    if not isinstance(raw, Mapping):
        raise DecisionError(f"{model_id} returned no answer for {question.name!r}.")
    kind = raw.get("type")
    if kind == "refusal":
        return refusal(question)
    if kind != _KINDS[question.kind]:
        raise DecisionError(
            f"{model_id} answered question {question.name!r} ({question.kind}) "
            f"with {dict(raw)!r}."

    try:
        confidence = raw.get("confidence")
        if question.kind == "predicate":
            probability = raw["noul"] if "noul" in raw else raw["probability"]
            return predicate_answer(question, float(probability), confidence)
        if question.kind == "choice":
            return Answer(
                name=question.name,
                kind="choice",
                value=str(raw["choice"]),
                probabilities={
                    str(k): float(v)
                    for k, v in (raw.get("probabilities") or {}).items()
                },
                confidence=confidence,
            )
        probabilities: dict[str, float] = {}
        for key, value in (raw.get("probabilities") or {}).items():
            level = _level_of(question, str(key))
            if level is None:
                raise ValueError(f"unknown level {key!r}")
            probabilities[level] = float(value)
        score = float(raw["score"])
        return Answer(
            name=question.name,
            kind="score",
            value=score,
            label=score_label(question, probabilities, score),
            probabilities=probabilities,
            confidence=confidence,
        )
    except (KeyError, TypeError, ValueError) as e:
        raise DecisionError(
            f"{model_id} returned a malformed answer for {question.name!r}: {dict(raw)!r}"
        ) from e

    def create_decision_model(
    model_id: str,
    *,
    api_key: Optional[str] = None,
    base_url: Optional[str] = None,
    settings: Optional[Any] = None,
) -> "DecisionModel":
    """Create a decision model from a ``provider/model`` id.

    Args:
        model_id: Provider-prefixed model id:

            - ``"openai/gpt-6-luna"``: the OpenAI Decisions API;
            - ``"gemini/gemini-decision-1"``: the Gemini Decisions API (key from
              ``GOOGLE_API_KEY`` or ``GEMINI_API_KEY``);
            - ``"openrouter/typesafe/jev-1.13"``: OpenRouter's decisions endpoint
              (key from ``OPENROUTER_API_KEY``);
            - ``"jev-compatible/<model>"``: any endpoint with Jev's request shape,
              with ``base_url`` the full endpoint URL;
            - ``"llm/<llm id>"``, e.g. ``"llm/anthropic/claude-haiku-5-5"``: any
              `create_llm` model through structured output, **without
              probabilities**.
        api_key: API key. If omitted, the provider's usual environment variable is used.
        base_url: Server URL (OpenAI), or the endpoint URL (OpenRouter,
            ``jev-compatible``), or the LLM's server URL (``llm/``).
        settings: A `DecisionSettings` or a compatible dict. Ignored by ``llm/``
            models; configure the LLM with `create_llm` and `LLMDecisionModel` instead.
    """
    from aatm.llm.decisions import DecisionSettings

    if "/" not in model_id:
        raise ValueError(
            "model_id must be prefixed with a provider, e.g. 'openai/gpt-6-luna'. "
            f"Got {model_id!r}. Available providers: "
            f"{', '.join(available_decision_providers())}"
        )
    provider, model = model_id.split("/", 1)
    if not model:
        raise ValueError(f"model_id has no model name: {model_id!r}")
    factory = _DECISION_PROVIDERS.get(provider)
    if factory is None:
        raise ValueError(
            f"Unknown decision provider {provider!r} in {model_id!r}. Available "
            f"providers: {', '.join(available_decision_providers())}. Use "
            "'llm/<llm id>' to answer with any LLM, or register one with "
            "register_decision_provider()."
        )
    if settings is None:
        decision_settings = DecisionSettings()
    elif isinstance(settings, DecisionSettings):
        decision_settings = settings
    elif isinstance(settings, dict):
        decision_settings = DecisionSettings(**settings)
    else:
        raise ValueError(
            "settings must be a DecisionSettings object or a compatible dict"
        )
    return factory(
        model, api_key=api_key, base_url=base_url, settings=decision_settings
    )
