    Decision models

    Decision models answer closed-set questions about a state (a text or a JSON record): pick one of several options, place it on an ordered scale, or answer yes or no. They return the answer with a probability per option, faster and cheaper than a generative LLM call, and write no text.

    Many steps of a mapping or extraction pipeline are decisions of this kind: choosing a candidate concept, labelling an attribute, checking that a mention is not negated. Two steps use them so far: DecisionSelector and DecisionAttributeLabeller; see issue #77 for the others planned on top of this interface.

    import asyncio

from aatm.llm import Question, create_decision_model

model = create_decision_model("openrouter/typesafe/jev-1.13")
decision = asyncio.run(
    model.decide(
        {"text": "creatinine", "unit": "mg/dl", "value": "1.4"},
        [
            Question.choice(
                "specimen",
                "Which specimen was the test most likely done on?",
                {"serum": "Serum or plasma", "urine": "Urine", "unknown": "Not stated"},
            ),
            Question.score(
                "abnormal", "How abnormal is the value?", ["normal", "mild", "severe"]
            ),
            Question.predicate("is_lab", "Is the text the name of a lab test?"),
        ],
    )
)
decision["specimen"].value          # "serum"
decision["specimen"].probabilities  # {"serum": 0.82, "urine": 0.11, "unknown": 0.07}
decision["abnormal"].label          # the most likely level
decision["is_lab"].probability      # probability of yes

    Model id Backend Key Probabilities

    gemini/gemini-decision-1 Gemini Decisions API (v1beta) GOOGLE_API_KEY or GEMINI_API_KEY yes

    jev-compatible/<model> + base_url Any endpoint with Jev's request shape: TypeSafe, Eden AI, a self-hosted model api_key= yes
    llm/<llm id>, e.g. llm/anthropic/claude-haiku-5-5 Any aatm.llm.create_llm model, through structured output the LLM's no

    llm/ models let pipeline steps run with any provider, or offline with a local model, but their answers carry no probabilities: thresholds on probabilities do not apply to them.

    Calls share the rate limits and retries of aatm.llm.limits, and are counted by aatm.llm.track_usage. OpenRouter reports each call's cost, which TokenUsage.cost uses when you give no price for the model.

    Pin versions

    Aliases such as jev-latest move: the answers behind cached results change. Use a versioned model id (typesafe/jev-1.13); aatm warns about latest and preview aliases.

    Data governance

    Decision backends send the state, e.g. a sentence of a clinical note, to the provider: OpenAI, Google, OpenRouter and TypeSafe, or Eden AI. Before sending protected health information, check the provider's data processing agreement (and BAA, where required) and its data retention. Use llm/ with a local model to keep data on your machine.

    Probabilities are not accuracy

    A confident answer can be wrong, and some models' probabilities shift with the order of the options. Calibrate thresholds on your own labelled data.

    Selecting concepts: DecisionSelector

    DecisionSelector is a selector of the terminology mapper. For each text, it asks the decision model one choice question: which of the top-k retrieved candidate concepts means the same as the text, or none. Expressions of the same standard concept (synonyms) are one option, so their probability is not split.

    from aatm.omop import OmopTableBuilder
from aatm.terminology_mapper import TerminologyMapper

mapper = TerminologyMapper(
    retriever="text-embedding-3-small",
    selector="decision-openrouter/typesafe/jev-1.13",
)
builder = OmopTableBuilder(definitions, mapper=mapper)

    Registered names are decision-openai/gpt-6-luna, decision-gemini/gemini-decision-1 and decision-openrouter/typesafe/jev-1.13; any other decision-<model id> works too, e.g. decision-llm/ollama/llama3.1:8b. To set top_k, the question, or the model's api_key, base_url and settings, build the selector:

    from aatm.selectors import DecisionSelector

selector = DecisionSelector(
    "jev-compatible/jev-1.13",
    top_k=5,
    model_kwargs={"base_url": "https://jev.example.org/v1/decisions"},
)

    The probability of the chosen concept is the mapping's score: the mapper's confidence_score and the builder's score. A min_score in a definition is therefore a threshold on the model's probability: map: {min_score: 0.8} keeps the concepts chosen with at least 80 %, and stores 0 with a low_confidence issue for the others. Each mapping's trace has the provider's model version and the probability of every option.

    llm/ models give no score

    With an llm/ model the selector still chooses, but the mappings have no score (confidence_score is empty): a min_score rejects all of them. aatm warns when you create such a selector.

    The coding cache (aatm.omop.CachedCoder) keys results on the selector's cache_identity(): the model id, top_k, the question and the endpoint. Changing any of them, e.g. moving from jev-1.13 to jev-1.14, codes the texts again. A moving alias (jev-latest) would not: pin versions.

    The texts to map and the candidate names are sent to the provider; see the data governance warning above. The API reference of DecisionSelector is on the Selectors page.

    Labelling attributes: DecisionAttributeLabeller

    An entity attribute with a closed list of labels, such as smoking_status.status or the ECOG grade, is a closed-set question. By default the extractor's own LLM call chooses the labels. To have a decision model label them instead, or check them, give the extractor a labeller:

    from aatm.extractors import DecisionAttributeLabeller
from aatm.omop import OmopExtractionPipeline

pipeline = OmopExtractionPipeline(
    ["smoking_status", "ecog_performance_status"],
    model_id="openai/gpt-5-mini",
    attribute_labeller=DecisionAttributeLabeller(
        "openrouter/typesafe/jev-1.13",
        mode="verify",
        min_probability=0.8,
    ),
)

    SimpleLLMExtractor(..., attribute_labeller=...) takes the same argument. Without it, nothing changes.

    Who labels is set in code; what kind of question each attribute is, in the definitions. The labeller sets the model, the mode, the attributes (attributes= ["smoking_status", "ecog_performance_status.score"]; all of them by default) and the threshold. The definition file says whether an attribute's labels form a scale: with ordered: true (the ECOG grades) the model answers a score question, which knows that grade 2 lies between 1 and 3; otherwise a choice question. The extractor ignores ordered, so the definition files work the same with or without a labeller.

    For each mention, the model reads the entity's name, the mention's text and its line of the note, and answers every labelled attribute of the mention in one call. Every question can be answered "not stated" (a not_stated option, or a yes/no "is it stated?" question next to a score), since a mention need not state every attribute: the attribute is then left out, as the extractor would.

    What the decision model reads

    A label can depend on more than the mention's line. In

    HOME MEDICATIONS:
- lisinopril 10 mg PO daily

    the drug is taken at home (kind: taking), but its line does not say so. Two options add more of the note to the state:

    Option Adds Cost per decision call
    section=True the nearest section heading above the line, as section: a short line that ends with :, starts with # or is in capitals without digits ("HOME MEDICATIONS:", "Mother:", "FAMILY HISTORY") a few tokens
    lines_before=n the n lines before the mention's line, as before the tokens of those lines 
    DecisionAttributeLabeller(
    "openrouter/typesafe/jev-1.13", mode="replace", section=True
)

    Both are off by default. Use section=True for notes with sections. In the benchmark it fixed nearly every label that depends on a heading, for about 2 tokens per call (a call is 800–1,000 tokens, mostly the questions). lines_before did no better than section, even when the heading was among the lines, and with long lines it adds many tokens to every call. Both send more of the note to the decision provider: a heading is one short line, lines_before whole lines of text.

    Choosing a mode

    mode is required: there is no default, so the code always says what runs.

    mode="verify" mode="replace"
    Extractor prompt unchanged: it finds the mentions and labels them, as without a labeller the labelled attributes are left out: it only finds the mentions
    Decision model labels each mention too labels each mention
    Label written only when both give the same answer (both "not stated" counts as agreeing) the decision model's answer
    A disagreement goes to review, nothing is written cannot happen: only one model labels
    Cost the extraction, plus one decision call per mention a smaller extraction, plus one decision call per mention
    Mentions without a required label the extractor rejects them, and the decision model never sees them the extractor keeps them; the decision model labels them
    What the decision model reads the mention and its line, and the section heading or lines before when asked the same
    Use it when your extractor is strong, and a wrong label costs more than a withheld one your extractor is small or cheap and struggles with the labels, and you have checked the decision model on your notes

    In the benchmark below:

    • verify wrote no wrong label with a strong extractor, and withheld a few correct labels for review instead.
    • replace with section=True was the most accurate and the cheapest with Jev or Gemini: with a small extractor, it beat a stronger extractor alone at a third of the cost.

    Without section=True, a label that depends on a section heading goes to review in verify and, when the attribute is required, loses the mention in replace.

    min_probability is a threshold on the decision model's probability. With min_probability=0.8, only labels the model gives at least 80 % are written. The default, None, keeps every label. Either way, the probability of each label written is in ExtractedEntity.attribute_probabilities (and EntityRecord.attribute_probabilities). llm/ models give no probabilities: with a threshold, all their labels go to review.

    Review. A label below the threshold, a disagreement (verify), or a refusal is not written: the mention keeps its other attributes, and the label goes to the result's attribute_reviews for a person to check, with the extractor's label, the decision model's label and its probability of each option. When the attribute is required, the mention is rejected (required_attribute_under_review), with its children, rather than written without it. The OMOP builder collects the reviews in OmopTables.attribute_reviews_dataframe(), and a run writes them to the attribute_reviews folder (OmopRun.attribute_reviews()).

    Runs. A run's stored results depend on the labeller as much as on the extractor: resuming with another labeller, mode, threshold or model is refused, as with another extractor. With batch=True, the labels are asked with live calls when a batch job's results come back, before they are stored; a run that stops meanwhile collects the job again and labels it then.

    Which mode: the benchmark

    benchmarks/attribute_labels labels 130 hand-written mentions (2026-11-12):

    • a basic set of 50 one-line smoking statuses and ECOG grades;
    • a hard set of 80: drug kind and route, family history relative, harder smoking and ECOG phrasing, and 18 labels that depend on a section heading in long notes.

    It compares two extractors, openai/gpt-5-mini and the smaller openai/gpt-5-nano, and three decision models. "Dropped" counts mentions that were found but rejected because a required attribute got no label.

    Hard set, 80 mentions (correct / wrong / review / dropped):

    replace, jev-1.13 57 / 5 / 0 / 18 79 / 1 / 0 / 0 1.63

    Label entity attributes with a decision model, with probabilities.

    An attribute with a closed list of labels, such as smoking_status.status or the ECOG grade, is a closed-set question. DecisionAttributeLabeller asks it of a decision model (aatm.llm.DecisionModel) for each mention the extractor found, and gets back the label with a probability.

    Opt in by giving the labeller to the extractor; without it, the extractor's own LLM call chooses the labels, as before:

    from aatm.extractors import DecisionAttributeLabeller, SimpleLLMExtractor

extractor = SimpleLLMExtractor(
    model_id="openai/gpt-5-mini",
    entity_definitions=definitions,
    attribute_labeller=DecisionAttributeLabeller(
        "openrouter/typesafe/jev-1.13",
        mode="verify",
        min_probability=0.8,
    ),
)

    The labeller decides who labels; the entity definitions say what kind of question each attribute is. An attribute marked ordered: true (its labels are a scale, lowest first, like the ECOG grades) is asked as a score question; any other as a choice question. Every question can also be answered "not stated", since a mention need not state every attribute.

    mode is required, with no default, so the code always says which one runs:

    • "verify": the extractor's prompt is unchanged and it labels as before. The decision model labels each mention too, and a label is written only when both give the same answer (both "not stated" counts as agreeing). Costs the extraction plus one decision call per mention.
    • "replace": the labelled attributes are left out of the extractor's prompt, so it only finds the mentions, and the decision model's label is written. The extraction prompt and output are smaller, so it costs less, but no second model checks the label.

    In both modes, a label the decision model is not sure of (below min_probability), that it refused to give, or (verify) that the two models disagree on, is not written to the entity: it goes to the result's attribute_reviews for a person to check. When such an attribute is required, the mention is rejected (required_attribute_under_review), with its children.

    Data governance: each mention and its line of the note are sent to the decision provider, and with section or lines_before, the heading and lines above it.

    the line, and the lines just before it.

    Args:

            one. ``"replace"``: the extractor's prompt leaves the attributes out
            and the decision model's label is written. See the module docs.

            attributes) or ``"<entity key>.<attribute key>"``. ``None`` (default):
            every attribute of every entity.

            instead of the entity. ``None`` (default): keep every label, recording

            every label to review.

            `is_heading`), e.g. "HOME MEDICATIONS:". Adds a few tokens per call.

            its tokens to every call, and more of the note goes to the provider.
        instructions: The text that starts every question. ``{entity}`` is replaced
            by the entity's name and ``{attribute}`` by the attribute's description.
        max_concurrency: Mentions labelled at the same time.
        model_kwargs: Passed to `create_decision_model` (``api_key``, ``base_url``,
            ``settings``) when `model` is an id.
    """

        section: bool = False,
        lines_before: int = 0,
        instructions: str = DEFAULT_INSTRUCTIONS,
        max_concurrency: int = 8,
        model_kwargs: Optional[Mapping[str, Any]] = None,
    ):
        from aatm.llm.decisions import DecisionModel, has_probabilities

        if mode not in ("verify", "replace"):
            raise ValueError("mode must be 'verify' or 'replace'")
        if min_probability is not None and not 0.0 <= min_probability <= 1.0:
            raise ValueError("min_probability must be between 0 and 1, or None")
        if max_concurrency < 1:
            raise ValueError("max_concurrency must be >= 1")
        if lines_before < 0:
            raise ValueError("lines_before must be >= 0")
        if isinstance(attributes, str):
            raise TypeError("attributes must be a list of names, not a string")
        if isinstance(model, str):
            from aatm.llm import create_decision_model

            model = create_decision_model(model, **dict(model_kwargs or {}))
        elif model_kwargs:
            raise ValueError("model_kwargs only applies when model is a model id")
        if not isinstance(model, DecisionModel):
            raise TypeError(
                "model must be a decision model id or a DecisionModel, got "
                f"{type(model).__name__}"
            )
        self.decision_model = model
        self.model_id: str = model.model_id
        self.mode: LabellerMode = mode
        self.attributes = list(attributes) if attributes is not None else None
        self.min_probability = min_probability
        self.section = section
        self.lines_before = lines_before
        self.instructions = instructions
        self.max_concurrency = max_concurrency
        self._semaphore: Optional[asyncio.Semaphore] = None
        if min_probability is not None and not has_probabilities(model):
            logger.warning(
                "%s gives no probabilities: with min_probability set, every label "
                "it gives goes to review.",
                self.model_id,
            )

    def targets(
        self, definitions: EntityDefinitions
    ) -> dict[str, list[AttributeDefinition]]:
        """The labelled attributes of each entity key, in definition order.

        Raises:
            ValueError: If `attributes` names an unknown entity or attribute, or an
                entity without attributes.
        """
        if self.attributes is None:
            return {
                e.key: list(e.attributes) for e in definitions.entities if e.attributes
            }
        wanted: dict[str, set[str]] = {}
        for name in self.attributes:
            entity_key, _, attribute_key = name.partition(".")
            entity = definitions.get(entity_key)
            if entity is None:
                raise ValueError(f"Unknown entity {entity_key!r} in attributes")
            if not entity.attributes:
                raise ValueError(f"Entity {entity_key!r} has no attributes")
            keys = wanted.setdefault(entity_key, set())
            if not attribute_key:
                keys.update(a.key for a in entity.attributes)
            elif entity.get_attribute(attribute_key) is None:
                raise ValueError(
                    f"Entity {entity_key!r} has no attribute {attribute_key!r}"
                )
            else:
                keys.add(attribute_key)
        return {
            e.key: [a for a in e.attributes if a.key in wanted[e.key]]
            for e in definitions.entities
            if e.key in wanted
        }

    # --- replace mode: the extractor leaves the attributes out ---------------------

    def prompt_definitions(self, definitions: EntityDefinitions) -> EntityDefinitions:
        """The definitions the extractor uses: without the labelled attributes in
        ``replace`` mode, unchanged in ``verify`` mode."""
        if self.mode == "verify":
            return definitions
        targets = self.targets(definitions)
        entities = []
        for entity in definitions.entities:
            labelled = {a.key for a in targets.get(entity.key, [])}
            if labelled:
                # model_copy skips validation: the omop block may refer to the
                # attributes left out, and is not used by the extractor.
                entity = entity.model_copy(
                    update={
                        "attributes": [
                            a for a in entity.attributes if a.key not in labelled
                        ]
                    }
                )
            entities.append(entity)
        return definitions.model_copy(update={"entities": entities})

    def strip_candidates(
        self, candidates: ExtractedEntityCandidates, definitions: EntityDefinitions
    ) -> ExtractedEntityCandidates:
        """In ``replace`` mode, drop labels the extractor gave anyway."""
        if self.mode == "verify":
            return candidates
        targets = {
            key: {a.key for a in attributes}
            for key, attributes in self.targets(definitions).items()
        }
        entities = [
            c.model_copy(
                update={
                    "attributes": [
                        a
                        for a in c.attributes
                        if a.key.strip().casefold() not in targets.get(c.key, set())
                    ]
                }
            )
            for c in candidates.entities
        ]
        return candidates.model_copy(update={"entities": entities})

    async def decide(
        self,
        entity: EntityDefinition,
        attributes: Sequence[AttributeDefinition],
        mention: str,
        line: str,
        context: Optional[Mapping[str, str]] = None,
    ) -> dict[str, AttributeDecision]:
        """Ask the attributes of one mention; return the answer of each, by key.

        `context` holds ``section`` and ``before``, when asked for
        (`mention_context`).
        """
        asked = [
            _AttributeQuestions(i, entity, a, self.instructions)
            for i, a in enumerate(attributes)
        ]
        questions = [q for a in asked for q in a.questions]
        if self._semaphore is None:
            self._semaphore = asyncio.Semaphore(self.max_concurrency)

                    "line": line,

    async def label(
        self,
        result: EntityValidationResult,
        segments: Sequence[TextSegment],
        definitions: EntityDefinitions,
    ) -> EntityValidationResult:
        """Label the attributes of each validated mention of `result`.

        Returns a new result: labels the model is sure of (and, in ``verify`` mode,
        agrees with) are kept, the others go to ``attribute_reviews``, and mentions
        left without a required attribute are rejected with their children.

        Raises:
            Exception: Any error of the decision model, once retries are spent.
        """
        targets = self.targets(definitions)
        lines = {s.id: s.text for s in segments}
        definitions_by_key = {e.key: e for e in definitions.entities}
        jobs = [
            (entity, definitions_by_key[entity.key], targets[entity.key])
            for entity in result.validated_entities
            if entity.key in targets
        ]
        decisions = await asyncio.gather(
            *(
                self.decide(
                    definition,
                    attributes,
                    entity.text,
                    lines.get(entity.line, ""),
                    mention_context(
                        segments, entity.line, self.section, self.lines_before
                    ),
                )
                for entity, definition, attributes in jobs
            )
        )
        result = result.model_copy(deep=True)
        by_id = {e.id: e for e in result.validated_entities}
        under_review: dict[str, set[str]] = {}
        for (entity, definition, attributes), answers in zip(jobs, decisions):
            kept = by_id[entity.id]
            for attribute in attributes:
                reason = self._apply(
                    kept, definition, attribute, answers[attribute.key], result
                )
                if reason is not None:
                    under_review.setdefault(kept.id, set()).add(attribute.key)
        return _reject_missing_required(result, targets, under_review, definitions)

    def _apply(
        self,
        entity: ExtractedEntity,
        definition: EntityDefinition,
        attribute: AttributeDefinition,
        answer: AttributeDecision,
        result: EntityValidationResult,
    ) -> Optional[AttributeReviewReason]:
        """Write one answer to `entity`, or send it to review; return the reason."""
        extractor_value = (
            entity.get_attribute(attribute.key) if self.mode == "verify" else None
        )
        reason: Optional[AttributeReviewReason] = None
        if answer.refused:
            reason = "refused"
        elif self.min_probability is not None and (
            answer.probability is None or answer.probability < self.min_probability
        ):
            reason = "low_probability"
        elif self.mode == "verify" and answer.label != extractor_value:
            reason = "disagreement"

        entity.attributes = [a for a in entity.attributes if a.key != attribute.key]
        entity.attribute_probabilities.pop(attribute.key, None)
        if reason is not None:
            result.attribute_reviews.append(
                AttributeReview(
                    entity_id=entity.id,
                    entity_key=entity.key,
                    text=entity.text,
                    attribute_key=attribute.key,
                    extractor_value=extractor_value,
                    decision_value=answer.label,
                    probability=answer.probability,
                    probabilities=answer.probabilities,
                    reason=reason,
                    model=self.model_id,
                )
            )
            return reason
        if answer.label is not None:
            entity.attributes.append(
                ExtractedAttribute(key=attribute.key, value=answer.label)
            )
            if answer.probability is not None:
                entity.attribute_probabilities[attribute.key] = answer.probability
        order = [a.key for a in definition.attributes]
        entity.attributes.sort(key=lambda a: order.index(a.key))
        return None

    def is_heading(text: str) -> bool:
    """Whether a line looks like a section heading of a note.

    A heading is a short line that ends with ``:`` ("HOME MEDICATIONS:",
    "Mother:"), starts with ``#``, or is written in capitals without digits

    text = text.strip()

        return False
    if text.startswith("#") or text.endswith(":"):
        return True
    letters = [c for c in text if c.isalpha()]
    return (
        len(letters) >= 3
        and not any(c.islower() for c in letters)
        and not any(c.isdigit() for c in text)
    )

    def mention_context(
    segments: Sequence[TextSegment],
    line_id: str,
    section: bool = False,
    lines_before: int = 0,
) -> dict[str, str]:
    """The parts of the note around a mention's line that the labeller adds to the
    state: ``before`` (the `lines_before` lines before it) and ``section`` (the
    nearest heading above it, unless ``before`` already holds it).
    """
    index = next((i for i, s in enumerate(segments) if s.id == line_id), None)
    if index is None:
        return {}
    context: dict[str, str] = {}
    first = max(index - lines_before, 0)
    if lines_before and first < index:
        context["before"] = "\n".join(s.text for s in segments[first:index])
    if section:
        heading = next(
            (j for j in range(index - 1, -1, -1) if is_heading(segments[j].text)),
            None,
        )
        if heading is not None and heading < first:
            context["section"] = segments[heading].text.strip()
    return context

    identity: dict[str, Any] = {"model_id": model.model_id}

    class OpenAIDecisionModel:
    """OpenAI models through the Decisions API, e.g. ``gpt-6-luna``.

    Answers come with probabilities per option and a confidence. Text states are
    sent as text; JSON objects, and arrays of objects, as ``input_json``.

    def __init__(
        self,
        model: str,
        *,
        api_key: Optional[str] = None,
        base_url: Optional[str] = None,
        settings: Optional[DecisionSettings] = None,
        client: Optional[AsyncOpenAI] = None,
    ):
        self.model = model
        self.model_id = f"openai/{model}"
        self.settings = settings or DecisionSettings()
        # Retries are handled by the shared limiter (`aatm.llm.limits`). One client
        # per event loop: openai 3.x binds its connection pool to the first loop.
        self._clients = PerEventLoop(
            lambda: AsyncOpenAI(api_key=api_key, base_url=base_url, max_retries=0)
        )
        if client is not None:
            self._clients.set(client)
        warn_if_unpinned(self.model_id)

    @property
    def client(self) -> AsyncOpenAI:
        """The client of the running event loop (or the one given)."""
        return self._clients.get()

    def request_body(
        self, state: State, questions: Sequence[Question]
    ) -> dict[str, Any]:
        """The JSON body of the request."""
        input_: Any
        if isinstance(state, dict) or (
            isinstance(state, list)
            and state
            and all(isinstance(s, dict) for s in state)
        ):
            content = [{"type": "input_json", "data": state}]
            input_ = [{"role": "user", "content": content}]
        else:
            input_ = state_text(state)
        return {
            "model": self.model,
            "input": input_,
            "questions": [_question(q) for q in questions],
            **self.settings.provider_kwargs,
        }

    async def decide(self, state: State, questions: Sequence[Question]) -> Decision:
        check_questions(questions)
        body = self.request_body(state, questions)
        return await get_rate_limiter(self.model_id).run(
            lambda: self._decide(body, questions),
            estimated_tokens=estimate_tokens(
                state_text(state), *(q.instructions for q in questions)
            ),
        )

    async def _post(self, body: dict[str, Any]) -> Any:
        """Send the request with ``client.decisions.create``; return a dict."""
        kwargs = {k: body[k] for k in _SDK_PARAMS if k in body}
        extra = {k: v for k, v in body.items() if k not in _SDK_PARAMS}
        if extra:
            kwargs["extra_body"] = extra
        if self.settings.timeout is not None:
            kwargs["timeout"] = self.settings.timeout
        decision = await self.client.decisions.create(**kwargs)
        return decision.model_dump()

    async def _decide(
        self, body: dict[str, Any], questions: Sequence[Question]
    ) -> Decision:
        response = await self._post(body)
        if not isinstance(response, dict):
            raise DecisionError(f"{self.model_id} returned no decision: {response!r}")
        usage = response.get("usage") or {}
        record_usage(
            usage.get("input_tokens"),
            usage.get("output_tokens"),
            model_id=self.model_id,
        )
        answers = response.get("answers") or []
        if len(answers) != len(questions):
            raise DecisionError(
                f"{self.model_id} returned {len(answers)} answers for "
                f"{len(questions)} questions."
            )
        return Decision(
            model=response.get("model") or self.model,
            answers=[_answer(self.model_id, q, a) for q, a in zip(questions, answers)],
        )

    async def _decide(
        self, body: dict[str, Any], questions: Sequence[Question]
    ) -> Decision:
        response = await self.client.aio.decisions.create(**body)
        data = response.model_dump() if hasattr(response, "model_dump") else response
        if not isinstance(data, Mapping):
            raise DecisionError(f"{self.model_id} returned no decision: {data!r}")
        usage = data.get("usage") or {}
        record_usage(
            usage.get("total_input_tokens"),
            usage.get("total_output_tokens"),
            model_id=self.model_id,
        )
        answers = data.get("answers")
        if not answers:
            feedback = data.get("prompt_feedback") or {}
            reason = feedback.get("block_reason")
            if reason is None:
                raise DecisionError(f"{self.model_id} returned no answers: {data!r}")

                "%s blocked the prompt (%s%s): every question is answered as refused.",
                self.model_id,
                reason,
                f": {feedback['block_reason_message']}"
                if feedback.get("block_reason_message")
                else "",
            )
            return Decision(model=self.model, answers=[refusal(q) for q in questions])
        return Decision(
            model=self.model,
            answers=[
                jev_answer(self.model_id, q, answers.get(q.name)) for q in questions
            ],
        )

    async def _post(self, client: httpx.AsyncClient, body: dict[str, Any]) -> Any:
        headers = {"Authorization": f"Bearer {self.api_key}"} if self.api_key else {}
        response = await client.post(
            self.url, json=body, headers=headers, timeout=self.settings.timeout
        )
        if response.status_code >= 400:
            raise DecisionHTTPError(
                f"{self.model_id} decision request failed "
                f"({response.status_code}): {response.text[:500]}",
                response,
            )
        return response.json()

    async def _decide(
        self, body: dict[str, Any], questions: Sequence[Question]
    ) -> Decision:
        if self.http_client is not None:
            response = await self._post(self.http_client, body)
        else:
            async with httpx.AsyncClient() as client:
                response = await self._post(client, body)
        if not isinstance(response, dict):
            raise DecisionError(f"{self.model_id} returned no decision: {response!r}")
        usage = response.get("usage") or {}
        cost = usage.get("cost")
        record_usage(
            usage.get("input_tokens"),
            usage.get("output_tokens"),
            model_id=self.model_id,
            cost=float(cost) if isinstance(cost, (int, float)) else None,
        )
        answers = response.get("answers")
        if not isinstance(answers, Mapping):
            raise DecisionError(f"{self.model_id} returned no answers: {response!r}")
        return Decision(
            model=response.get("model") or self.model,
            answers=[
                jev_answer(self.model_id, q, answers.get(q.name)) for q in questions
            ],
        )

    def jev_answer(model_id: str, question: Question, raw: Any) -> Answer:
    """Parse an answer in Jev's shape (also the Gemini Decisions API's).

    Raises:
        DecisionError: If the answer is missing, of the wrong type or malformed.
    """
    if not isinstance(raw, Mapping):
        raise DecisionError(f"{model_id} returned no answer for {question.name!r}.")
    kind = raw.get("type")
    if kind == "refusal":
        return refusal(question)
    if kind != _KINDS[question.kind]:
        raise DecisionError(
            f"{model_id} answered question {question.name!r} ({question.kind}) "
            f"with {dict(raw)!r}."
        )
    try:
        confidence = raw.get("confidence")
        if question.kind == "predicate":
            probability = raw["noul"] if "noul" in raw else raw["probability"]
            return predicate_answer(question, float(probability), confidence)
        if question.kind == "choice":
            return Answer(
                name=question.name,
                kind="choice",
                value=str(raw["choice"]),
                probabilities={
                    str(k): float(v)
                    for k, v in (raw.get("probabilities") or {}).items()
                },
                confidence=confidence,
            )
        probabilities: dict[str, float] = {}
        for key, value in (raw.get("probabilities") or {}).items():
            level = _level_of(question, str(key))
            if level is None:
                raise ValueError(f"unknown level {key!r}")
            probabilities[level] = float(value)
        score = float(raw["score"])
        return Answer(
            name=question.name,
            kind="score",
            value=score,
            label=score_label(question, probabilities, score),
            probabilities=probabilities,
            confidence=confidence,
        )
    except (KeyError, TypeError, ValueError) as e:
        raise DecisionError(
            f"{model_id} returned a malformed answer for {question.name!r}: {dict(raw)!r}"
        ) from e
