    Command Line Interface

    This module defines the main Typer application for the Any-to-Any Terminology Mapping (AATM) package. It provides commands for initializing the local project environment, launching the search user interface, and running terminology mapping tasks from either a config file or command-line options.

    The CLI is responsible for orchestrating high-level workflows such as:

    • setting up local helper directories and Git ignore rules
    • validating vocabulary and embedding model inputs
    • building local SQLite and vector databases for terminology mapping
    • collecting interactive user input for setup choices
    • loading and displaying mapping task configurations
    • starting synchronous terminology mapping runs
    • launching the Streamlit-based search interface

    Commands:

    • init: Set up the local environment for OMOP vocabulary processing and vector database creation.

    • search-ui: Launch the Streamlit-based search interface.

    • map: Run a terminology mapping task from a configuration file or from explicit CLI arguments.

    • amap: Placeholder for future asynchronous mapping support.

    • serve: Serves a minimal FastAPI application with AATM's functionality.

    • doctor: Check whether local models can use a GPU and print the commands that enable it.

    Attributes:

    Name Type Description
    LOCAL_HELPER_PATH Path

    Path to the local helper directory used by AATM to store generated artifacts and local resources.
    DEFAULT_VOCAB_DIR Path

    Default directory containing OMOP vocabulary files.
    DEFAULT_EMBEDDING_MODEL str

    Default embedding model used when building the local vector database.
    SUPPORTED_EMBEDDING_MODELS List[str]

    List of embedding model identifiers supported by the CLI setup workflow.
    STANDARD_VOCABULARIES List[str]

    List of supported standard vocabularies available for terminology mapping.
    DEFAULT_STANDARD_VOCABULARIES List[str]

    Default subset of standard vocabularies selected during initialization.
    AATM_LOGO str

    Multiline ASCII logo displayed in the CLI welcome screen.

    Examples:

    Initialize the local environment with defaults:

    $ aatm init

    Initialize with a custom vocabulary directory:

    $ aatm init --vocab-dir ./vocabularies

    Run a mapping task from a config file:

    $ aatm map --task-config-path config.yaml

    Run a mapping task from explicit options:

    $ aatm map --input-file concepts.csv --output-dir outputs \
    --translator-id my_translator --retriever-id my_retriever \
    --selector-id my_selector

    Launch the search UI:

    $ aatm search-ui

    Check GPU support:

    $ aatm doctor
    Note

    This module is intended to serve as the main CLI entrypoint for the package. It coordinates user interaction and delegates implementation details to lower-level utilities and domain-specific components.

    ensure_utf8_output()

    Make the CLI's output streams UTF-8 so non-ASCII output cannot crash it.

    On Windows, Python uses the legacy code page (e.g. cp1252) when stdout/stderr are redirected to a file or pipe, and printing the logo or other non-ASCII text then raises UnicodeEncodeError. Interactive consoles already use UTF-8 and are left as they are. PYTHONIOENCODING is set so that subprocesses started by the CLI (serve, search-ui) behave the same, unless the user already set it.

    def ensure_utf8_output() -> None:
    """Make the CLI's output streams UTF-8 so non-ASCII output cannot crash it.

    On Windows, Python uses the legacy code page (e.g. cp1252) when stdout/stderr are
    redirected to a file or pipe, and printing the logo or other non-ASCII text then
    raises `UnicodeEncodeError`. Interactive consoles already use UTF-8 and are left
    as they are. `PYTHONIOENCODING` is set so that subprocesses started by the CLI
    (`serve`, `search-ui`) behave the same, unless the user already set it.
    """
    for stream in (sys.stdout, sys.stderr):
        encoding = (getattr(stream, "encoding", None) or "").replace("-", "").lower()
        reconfigure = getattr(stream, "reconfigure", None)
        if encoding != "utf8" and reconfigure is not None:
            try:
                reconfigure(encoding="utf-8")
            except (ValueError, OSError):
                # Not reconfigurable (e.g. already written to in a way that
                # prevents it); keep the original stream.
                pass

    os.environ.setdefault("PYTHONIOENCODING", "utf-8")

    def prepare_vocab_bundle(
    source: str,
    vocab_dir: Path,
    *,
    force: bool = False,
    umls_api_key: Optional[str] = None,
    standard_vocabs: Optional[List[str]] = None,
) -> Path:
    """Download (if needed), unpack and check an Athena vocabulary bundle.

    Args:
        source: The bundle's download link, or the path of the zip.
        vocab_dir: Directory to unpack the bundle into.
        force: Overwrite existing files in `vocab_dir` without asking.
        umls_api_key: UMLS API key for the CPT4 step; skipped when missing.
        standard_vocabs: Standard vocabularies the user asked for, to warn
            when the bundle does not include them.

    Returns:
        The directory holding the vocabulary CSVs.

    Raises:
        typer.Exit: With a message when any step fails.
    """
    from rich.progress import (
        BarColumn,
        DownloadColumn,
        Progress,
        TimeRemainingColumn,
        TransferSpeedColumn,
    )

    from aatm import vocab_bundle as vb

    console.print("[blue]0) Preparing the Athena vocabulary bundle[/blue]")
    try:
        if vb.is_url(source):
            console.print("Downloading the bundle...")
            with Progress(
                "[progress.description]{task.description}",
                BarColumn(),
                DownloadColumn(),
                TransferSpeedColumn(),
                TimeRemainingColumn(),
                console=console,
                transient=True,
            ) as bar:
                task = bar.add_task("Downloading", total=None)
                zip_path = vb.download_bundle(
                    source,
                    LOCAL_HELPER_PATH / "downloads",
                    progress=lambda done, total: bar.update(
                        task, completed=done, total=total
                    ),
                )
            console.print(f"Saved the bundle to '{zip_path}'.")
        else:
            zip_path = Path(source).expanduser()

        console.print(f"Unpacking '{zip_path}' into '{vocab_dir}'...")
        try:
            vb.unpack_bundle(zip_path, vocab_dir, overwrite=force)
        except vb.VocabFilesExistError as e:
            if not sys.stdin.isatty():
                console.print(
                    f"[yellow]OOPS![/yellow] {e}. Pass --force to overwrite them, "
                    "or choose another directory with --vocab-dir.\n"
                )
                raise typer.Exit(1)
            if not questionary.confirm(f"{e}. Overwrite them?", default=False).ask():
                console.print(
                    "Nothing was overwritten. Choose another directory with "
                    "--vocab-dir, or pass --force.\n"
                )
                raise typer.Exit(1)
            vb.unpack_bundle(zip_path, vocab_dir, overwrite=True)
    except vb.VocabBundleError as e:
        console.print(f"[yellow]OOPS![/yellow] {e}\n")
        raise typer.Exit(1)

    missing = vb.missing_required_files(vocab_dir)
    if missing:
        console.print(
            f"[yellow]OOPS![/yellow] The bundle is missing required files: "
            f"{', '.join(missing)}. Request a new bundle at {vb.ATHENA_URL}.\n"
        )
        raise typer.Exit(1)

    if vb.has_cpt4_tooling(vocab_dir):
        if not umls_api_key:
            console.print(
                "[yellow]Warning:[/yellow] the bundle includes CPT4, but no UMLS "
                "API key was given, so CPT4 concepts will have no names. Pass "
                f"--umls-api-key or set {vb.UMLS_API_KEY_ENV_VAR} to add them "
                "(get a key at https://uts.nlm.nih.gov/uts/profile)."
            )
        else:
            console.print("Adding CPT4 concept names (this can take a while)...")
            try:
                vb.run_cpt4(vocab_dir, umls_api_key)
            except vb.Cpt4Error as e:
                console.print(f"[yellow]OOPS![/yellow] {e}\n")
                raise typer.Exit(1)

    vocabularies = vb.read_bundle_vocabularies(vocab_dir)
    listed = sorted(
        (v for v in vocabularies if not v.omop_generated),
        key=lambda v: v.vocabulary_id.lower(),
    )
    if listed:
        console.print(f"The bundle contains {len(listed)} vocabularies:")
        for v in listed:
            console.print(f"  - {v.vocabulary_id}: {v.version or 'no version'}")
    internal = len(vocabularies) - len(listed)
    if internal:
        console.print(
            f"  and {internal} vocabularies generated by OMOP (Visit, Gender, ...)."
        )
    present = {v.vocabulary_id for v in vocabularies}
    for vocab in standard_vocabs or []:
        if vocab not in present:
            console.print(
                f"[yellow]Warning:[/yellow] {vocab} was requested with "
                "--standard-vocabs but is not in the bundle."
            )
    console.print("[green]Done![/green]\n")
    return vocab_dir

    init(vocab_dir=None, embedding_model=None, embedding_dtype=None, standard_vocabs=None, vector_db=None, vocab_zip=None, force=False, umls_api_key=None)

    Initialize the local AATM environment.

    This command prepares the local project environment required for terminology mapping with OMOP vocabularies. It creates the helper directory used by AATM, ensures .aatm is listed in .gitignore, validates user inputs, builds the local SQLite vocabulary database, prepares mapping datasets for the selected standard vocabularies, and creates the local vector database used for retrieval.

    When embedding_model or standard_vocabs are not provided, the command interactively prompts the user to choose among the supported options.

    Parameters:

    Name Type Description Default
    vocab_dir Annotated[Optional[Path], Option(--vocab - dir, -vd, help='Path to the OMOP vocabularies directory.', show_default=False)]

    Path to the directory containing the OMOP vocabulary files. If not provided, the default vocabulary directory is used.

    		 None
    embedding_model Annotated[Optional[str], Option(--embedding - model, -e, help='Name of the embedding model to use.', show_default=False)]

    Name of the embedding model to use for building the local vector database. If not provided, the user is prompted to select one interactively.

    		 None
    embedding_dtype Annotated[Optional[str], Option(--embedding - dtype, help="Precision for local embedding models: float32, bfloat16 or float16. Defaults to the precision of the model's checkpoint. Half precision is faster and uses less GPU memory, but requires an NVIDIA GPU. Overrides AATM_EMBEDDING_DTYPE.", show_default=False)]

    Precision for local embedding models. If not provided, AATM_EMBEDDING_DTYPE is used, and otherwise the precision of the model's checkpoint.

    		 None
    standard_vocabs Annotated[Optional[List[str]], Option(--standard - vocabs, -sv, help=f'List of standard vocabularies to use. Available options: {STANDARD_VOCABULARIES}.')]

    List of standard vocabularies to include in the mapping datasets. If not provided, the user is prompted to select one or more interactively.

    		 None
    vector_db Annotated[Optional[str], Option(--vector - db, help="Where to build the vector database: 'local' (ChromaDB on this machine), 'cloud' (Chroma Cloud, configured with CHROMA_API_KEY) or 'pinecone' (configured with PINECONE_API_KEY). Overrides AATM_VECTOR_DB. Defaults to 'local'.", show_default=False)]

    Where to build the vector database, local, cloud or pinecone. If not provided, AATM_VECTOR_DB is used, and otherwise local.

    		 None
    vocab_zip Annotated[Optional[str], Option(--vocab - zip, help='Athena vocabulary bundle to set up from: the download link Athena emailed, or the path of the downloaded zip. It is unpacked into --vocab-dir (default ./vocabularies).', show_default=False)]

    An Athena vocabulary bundle, as its download link or the path of the zip. It is downloaded if needed, unpacked into vocab_dir, and its CPT4 names are added when it includes CPT4.

    		 None
    force Annotated[bool, Option(--force, help='With --vocab-zip, overwrite existing vocabulary files without asking.')]

    Overwrite existing vocabulary files when unpacking vocab_zip without asking.

    		 False
    umls_api_key Annotated[Optional[str], Option(--umls - api - key, envvar=UMLS_API_KEY, help='UMLS API key used to add the CPT4 names when the bundle includes CPT4. Read from UMLS_API_KEY when not given.', show_default=False, show_envvar=True)]

    UMLS API key for the CPT4 step. If not provided, UMLS_API_KEY is used; without a key the CPT4 step is skipped.

    		 None

    Raises:

    Type Description
    Exit

    If the vocabulary directory does not exist, if the embedding model is not supported, if any provided standard vocabulary is invalid, or if the vector database configuration is invalid.

    Examples:

    Initialize using the default vocabulary directory:

    $ aatm init

    Initialize with a custom vocabulary directory:

    $ aatm init --vocab-dir ./vocabularies

    Set up from the bundle link Athena emailed, or from the downloaded zip:

    $ aatm init --vocab-zip "https://athena.ohdsi.org/api/v1/vocabularies/zip/<id>"

    $ aatm init --embedding-model qwen3-4B

    $ aatm init --embedding-model qwen3-4B --embedding-dtype bfloat16

    $ aatm init --vector-db cloud

    Build the vector database in Pinecone (needs PINECONE_API_KEY and the aatm[pinecone] extra):

    $ aatm init --vector-db pinecone

def doctor() -> None:
    """Diagnose GPU support for local models.

    Compares the NVIDIA driver (via ``nvidia-smi``) with the installed PyTorch
    build and prints the commands that enable GPU acceleration. It does not
    change the environment.

    Raises:
        typer.Exit: With code 1 when an action is needed to enable the GPU.
    """
    from rich.table import Table

    from aatm.device import DEVICE_ENV_VAR, get_device
    from aatm.doctor import collect_driver_info, collect_torch_info, diagnose

    driver = collect_driver_info()
    torch_info = collect_torch_info()

    table = Table(show_header=False, box=None, padding=(0, 2))
    table.add_column(style="bold", no_wrap=True)
    table.add_column(overflow="fold")
    table.add_row("Python", sys.executable)
    table.add_row(
        "PyTorch",
        f"{torch_info.version} "
        + (f"(CUDA {torch_info.cuda})" if torch_info.cuda else "(CPU-only build)"),
    )
    if driver is None:
        table.add_row("NVIDIA driver", "not found")
    else:
        max_cuda = (
            f"{driver.max_cuda[0]}.{driver.max_cuda[1]}" if driver.max_cuda else "?"
        )
        table.add_row("NVIDIA GPU", driver.gpu_name or "unknown")
        table.add_row(
            "NVIDIA driver",
            f"{driver.driver_version or 'unknown'} (supports CUDA up to {max_cuda})",
        )
    try:
        device_label: str = get_device()
    except ValueError as e:
        device_label = f"error: {e}"
    table.add_row("AATM device", device_label)
    if os.environ.get(DEVICE_ENV_VAR):
        table.add_row(DEVICE_ENV_VAR, os.environ[DEVICE_ENV_VAR])

    console.print(table)
    console.print()

    diagnosis = diagnose(driver, torch_info)
    style = {"ok": "green", "info": "blue", "action": "yellow"}[diagnosis.status]
    console.print(f"[bold {style}]{diagnosis.summary}[/bold {style}]")
    for line in diagnosis.details:
        console.print(line)
    if diagnosis.commands:
        console.print()
        for command in diagnosis.commands:
            # Print commands verbatim (no markup, no wrapping) so they can be copied.
            console.print(command, markup=False, highlight=False, soft_wrap=True)

    if diagnosis.status == "action":
        raise typer.Exit(code=1)

    """Print the number of entries, their size and the coder identities they belong to."""
    from rich.table import Table
